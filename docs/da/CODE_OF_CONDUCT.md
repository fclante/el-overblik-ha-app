# Adfærdskodeks

[Read in English](../../CODE_OF_CONDUCT.md) · [Projektoversigt](README.md)

Dette projekt er et uafhængigt community-projekt. Vi ønsker deltagelse, der er imødekommende, respektfuld og fokuseret på at forbedre integrationen.

## Forventet adfærd

- Vær hensynsfuld, konstruktiv og respektfuld over for forskellige erfaringer og synspunkter.
- Giv feedback på idéer og kode, ikke på personlige egenskaber.
- Tag ansvar for fejl, og hjælp med at holde diskussioner nyttige.
- Beskyt andres privatliv. Offentliggør ikke legitimationsoplysninger, fulde målepunkts-ID'er, kontooplysninger eller personlige API-data.

## Uacceptabel adfærd

Chikane, fornærmelser, diskrimination, trusler, bevidst intimidering, doxxing og gentagen forstyrrende adfærd accepteres ikke. Brug ikke projektets diskussioner til at afsløre private oplysninger eller opfordre til usikker deling af legitimationsoplysninger eller kundedata.

## Håndhævelse og rapportering

Projektets vedligeholdere kan redigere eller fjerne upassende projektbidrag og kan begrænse deltagelse i projektets rum. **Rapporter via GitHubs “Report abuse” håndteres af GitHub**, ikke af dette projekt; brug [GitHubs side til rapportering af misbrug](https://github.com/contact/report-abuse), hvis GitHub bør gennemgå adfærd på GitHub. Brug ikke offentlige issues i projektet til at rapportere følsomme sikkerhedssårbarheder; følg [SECURITY.md](../../SECURITY.md).
