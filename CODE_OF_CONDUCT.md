# Code of Conduct

[Læs på dansk](docs/da/CODE_OF_CONDUCT.md) · [Project overview](README.md)

This project is an independent community effort. We want participation to be welcoming, respectful, and focused on improving the integration.

## Expected behavior

- Be considerate, constructive, and respectful of differing experience and viewpoints.
- Give feedback about ideas and code, not personal characteristics.
- Accept responsibility for mistakes and help keep discussions useful.
- Protect other people's privacy. Do not publish credentials, full meter IDs, account information, or personal API data.

## Unacceptable behavior

Harassment, insults, discrimination, threats, deliberate intimidation, doxxing, and repeated disruptive behavior are not acceptable. Do not use project discussions to expose private information or to encourage unsafe disclosure of credentials or customer data.

## Enforcement and reporting

Project maintainers may edit or remove inappropriate project contributions and may restrict participation in project spaces. **GitHub's “Report abuse” reports are handled by GitHub**, not by this project; use [GitHub's report abuse page](https://github.com/contact/report-abuse) for conduct on GitHub that should be reviewed by GitHub. Do not use public project issues to report sensitive security vulnerabilities; follow [SECURITY.md](SECURITY.md).
